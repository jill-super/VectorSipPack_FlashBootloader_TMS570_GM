# vFlash tool template

**Path:** `FlashTool/` — `vFlashTemplateInstaller_GM_SLP5.exe`, `seedkey.zip`.

**Purpose.** Template installer for the vFlash programming tool (GM SLP5) plus seed/key material placeholder. Run the installer on Windows; keep `seedkey.zip` with the matching bootloader/SecMod configuration.

> Tool binaries keep Vector’s license; they are not covered by the repo MIT `LICENSE`.
