# TMS570 GM Flash Bootloader

An AUTOSAR-based **flash bootloader** for the Texas Instruments **TMS570** (GM SLP5) — diagnostics over CAN (UDS / ISO-15765), secure download containers, and flash programming.

> **Vector vs. custom — read this first.**
> Most of `BSW/` is **Vector-provided** (MICROSAR-style SIP, GENy-generated). Board/application glue, demo apps, header/container scripts and tool configs are **custom**. Every module page carries an origin badge so you never mix the two. Do not modify Vector files without written permission (warranty note in the SIP ReadMe).

## At a glance

| Item | Value (from repo) |
|---|---|
| MCU | TI TMS5700714PGEQQ1 (Cortex-R4, F021 Flash API) |
| OEM / package | GM SLP5 (`FBL Gm SLP5 D00`) |
| License serial | CBD1400501, SIP 05.03.02, delivery 2014-12-24 |
| Toolchain | TI Code Composer Studio 4.9.5, GNU Make 3.79.1 (Windows), GENy 01.04.0043 |
| Transport / diagnostics | CAN, ISO-TP, UDS-style GM diagnostics |
| Security | HIS Security Module (CRC + verification classes, demo RSA-2048 keys only) |
| Build entry points | `BSW/Flash/Build/m.bat`, `Demo/DemoFbl/Appl/m.bat`, `Demo/DemoAppl/Appl/m.bat` |

## How to use this site

- Module pages are **factual and code-based**: purpose, origin badge, key files, public API, usage snippet, dependencies, and links to converted references.
- Converted pages (labelled “(converted)”) are **text extractions** of the original PDFs/HTML/TXT. Layout, figures and exact tables live in the originals under `Doc/`, `Misc/`, and `BSW/Flash/Build/`.
- No user/repo names appear in links or config, so **forks publish unchanged** — enable Pages from Actions and use your fork’s Pages URL.

## Build in 60 seconds

```bat
REM Flash driver (Windows, CCS 4.9.5 on PATH)
cd BSW\Flash\Build
m.bat

REM Bootloader integration example
cd ..\..\..\Demo\DemoFbl\Appl
m.bat

REM Demo application
cd ..\..\..\Demo\DemoAppl\Appl
m.bat
```

See [Build & integration](/layers/tools/) and each module’s “Build” section for details.
